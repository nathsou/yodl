# Yodl Language Support

This extension provides basic syntax highlighting for the custom Yodl HDL language in VS Code.

## Features

- Highlights keywords such as `module`, `let`, `match`.
- Recognizes basic numeric constants, operators, and line comments.

## Usage

1. Open this folder in VS Code.
2. Press F5 to launch a new VS Code window with the extension loaded.
3. Open any `.yodl` file to see the syntax highlighting.
